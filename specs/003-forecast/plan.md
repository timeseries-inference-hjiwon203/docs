## Summary

과제 2의 5분 칸 표로 "지난 2시간 → 다음 60분(12칸) CO₂·온도"를 맞히는 딥러닝 모델을 Jetson에서 학습한다.
GRU 1종으로 확인 기준(60분 CO₂ 30% 개선, 온도 개선)을 먼저 노린 뒤, 심화(B)로 모델 3종 × 과거 길이 3종,
일정 정보 포함/제외, 처음 보는 공간 시험을 같은 코드에 설정만 바꿔 돌린다.
채점은 과제 2의 `eval_points.csv.gz` 시점 그대로 해서 기준선과 나란히 비교한다.

## 입력과 출력

**기준 시각 t** (5분 칸 하나)마다 표본 하나.

과거 칸 (t-L+5분 ~ t, L = 1·2·4시간 → 12·24·48칸), 칸마다:

| 묶음 | 항목 | 만드는 법 |
|---|---|---|
| 센서 | co2, temperature, humidity | 학습 기간 평균·표준편차로 정규화 (`norm_stats.json`) |
| 채움 표시 | filled_co2 등 | 진짜 값이 아니라 채운 칸이면 1 |
| 시간 | 시각 sin·cos, 요일 sin·cos | 23시와 0시, 일요일과 월요일이 가깝게 |
| 공간 | is_lab (실습실 1, 회의실 0) | 한 모델로 두 공간을 학습 |
| 일정 | class_day, in_class(09~18시, 점심 제외), lunch(11:30~13:00), headcount | 일정 제외 모델에서는 이 묶음을 0으로 채우지 않고 **입력에서 아예 뺀다** |

앞으로 60분 칸 (t+5분 ~ t+60분, 12칸): 시간(sin·cos) + 일정 묶음. 미리 알 수 있는 정보만.

**인원(headcount)**: 이전 기수 2025-09-03 ~ 2025-12-31 40명(추정), 2026-01-01 ~ 08-31 48명(45~50명 가운데), 2026-09-01 ~ 09-22 45명, 휴강 09-23 ~ 09-30 0명, 2026-10-01 ~ 17명. 50으로 나눠 넣는다. 회의실도 같은 값을 쓴다(그 시기 교육장 이용 인원). 이전 기수 경계(2025-12말)는 정확한 날을 몰라 1월 1일로 둔다

**출력**: 12칸 × (CO₂, 온도) = 24개.
- 변화량 방식(기본): 정답 = (x(t+h) - x(t)) / 학습 기간 표준편차. 예측값 = x(t) + 출력 × 표준편차
- 미래 값 방식(비교용): 정답 = 정규화한 x(t+h)

## 모델

세 모델 모두 같은 틀: **과거 칸을 읽는 몸통 → 마지막 요약(숫자 64개) + 앞으로 60분 일정 → 작은 출력층 → 24개**.

| 모델 | 몸통 | 크기(시작값) |
|---|---|---|
| GRU | GRU 2층, 숨은 크기 64 | 약 4만 빈칸 |
| LSTM | LSTM 2층, 숨은 크기 64 | 약 5만 |
| TCN | 3칸 창, 간격 1·2·4·8(48칸이면 16 추가), 채널 64, 과거만 보는 창 | 약 5만 |

크기·층 수는 처음에는 고정하고, 검증 점수가 확실히 나쁠 때만 바꾼다(바꾸면 기록).

## 학습

| 항목 | 값 | 이유 |
|---|---|---|
| 학습 표본 | 학습 기간에서 과거 칸이 모두 있고(15분 채움 후), 정답 12칸 중 진짜 값이 하나라도 있는 t | 빈 입력으로 배우지 않게 |
| 오차 함수 | 진짜 값인 정답 칸만 MAE (CO₂와 온도는 정규화된 크기로 더함) | 채점 지표와 같게, 채운 정답으로 배우지 않게 |
| 최적화 | Adam, 학습률 0.001, 묶음 256 | 흔한 시작값 |
| 멈춤 | 검증(9월) MAE가 10에폭 연속 안 좋아지면 멈추고 가장 좋던 때를 저장, 최대 100에폭 | 외우기(과적합) 방지 |
| 검증 점수 | 9월 채점 시점(eval_points의 val)에서 60분 CO₂ MAE를 원래 단위로 | 확인 기준이 60분 CO₂라서 |
| 씨앗 | 고정(기본 0). 최종 후보는 씨앗 3개 평균도 본다 | 우연히 좋게 나온 것인지 확인 |

## 평가

- `eval_points.csv.gz`의 (공간, 항목, 기준 시각, 시점) 그대로 예측해 MAE를 낸다. 과제 2 기준선 표와 같은 행 수여야 한다(확인)
- 채점 시점의 과거 칸에 긴 빈 칸이 있으면 앞 값으로 더 채우고 채움 표시를 1로 둔다. 모든 채점 시점에서 예측값을 낸다
- **시험 기간 규칙**: 모든 설정 고르기는 검증(9월)으로만 한다. 고른 설정을 `selected.json`에 적어 둔 **뒤에** 시험(10월)을 한 번 채점한다(`--final`). 그 뒤에는 설정을 바꾸지 않는다

## 분석 (US3)

- 공간 × 시점별 MAE 표 (기준선 3종 + 모델)
- 시간대별 60분 CO₂ 오차 (수업 시작 전후, 점심, 퇴실, 밤)
- 오차가 가장 큰 사례 5개씩 그래프: 실제 값, 현재값 유지, 모델
- 9월(45명)과 10월(17명) 오차 비교: 인원 정보가 시기 차이를 잡았는지
