**Feature Branch**: `003-forecast`

**Created**: 2026-10-22

**Status**: 확정 (2026-10-25, Q1~Q9 결정). 다음은 [plan.md](plan.md), [tasks.md](tasks.md)

**Input**: 과제 안내문 "과제 3. 60분 예측" — 환기와 냉난방을 미리 하려면 60분 앞까지 5분 간격으로
CO₂와 온도를 예측해야 한다. 딥러닝 모델(LSTM·GRU·TCN 중 최소 1종)을 학습해 과제 2 기준선과 같은 시점에서 비교한다.

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 입력과 출력을 설계한다 (Priority: P1) 🎯 MVP

- 과거를 얼마나 볼 것인가 (30분? 2시간? 하루?)
- 어떤 정보를 넣을 것인가: CO₂·온도·습도, 시간대·요일, 어느 공간인지, 일정(수업·예약)
- 60분을 한 번에 출력할지, 한 칸씩 반복해서 예측할지

**Why this priority**: 모델 종류보다 "무엇을 보고 무엇을 맞히나"가 결과를 더 크게 바꾼다. 과제 8 서비스도 같은 입력을 만들어야 한다.

**Independent Test**: 학습 표본 하나를 꺼내 입력 칸(시각·항목)과 정답 칸 12개를 사람이 눈으로 확인할 수 있다.

---

### User Story 2 - 딥러닝 모델을 학습하고 기준선과 비교한다 (Priority: P1)

- LSTM, GRU, TCN 중 최소 1종 학습 (심화 B는 3종 비교)
- 과제 2와 같은 시점(`eval_points.csv.gz`)에서 5·15·30·60분 뒤 MAE 비교

**Independent Test**: 기준선 3종 + 학습 모델 × 4시점 × CO₂·온도 × 공간 MAE 표가 나온다.

---

### User Story 3 - 공간별로 나눠 본다 (Priority: P2)

어느 공간에서 잘 맞고 어느 공간에서 안 맞는지, 그 이유를 분석한다. 오차가 가장 큰 순간(수업 시작, 점심, 퇴실, 창문 개방 추정)을 찾는다.

**Independent Test**: 공간 × 시간대(또는 상황)별 오차 표와 오차가 가장 컸던 사례 몇 개의 그래프가 나온다.

---

### User Story 4 - 일정 정보의 가치를 잰다 (Priority: P2)

일정을 입력에서 뺀 모델과 비교해 "일정 정보를 넣으면 60분 예측 오차가 ○ppm 줄어든다"를 숫자로 답한다.

**Independent Test**: 같은 모델·같은 시점에서 일정 포함/제외 두 줄의 MAE가 나온다.

---

### User Story 5 - 심화(B) (Priority: P3)

- 과거 길이(1·2·4시간) × 모델 종류(LSTM·GRU·TCN)를 바꿔 비교하고 최적 조합을 근거와 함께 제시 (검증 기간으로 고르고 시험 기간은 마지막에 한 번)
- 미래에 알 수 있는 정보(수업 시간표, 회의실 예약)를 입력에 넣는 방법을 설계하고 회의실 예측이 나아지는지 보인다. 회의실 예약 자료가 없으면 수업 시간표로만 하고 그 한계를 적는다
- 한 공간을 학습에서 완전히 빼고, 처음 보는 공간에서도 예측이 되는지 시험한다 (실습실만으로 학습 → 회의실 채점, 반대도)

**Independent Test**: 9개 조합의 검증 MAE 표, 일정 포함/제외 회의실 MAE, 공간 빼기 시험 MAE 표가 나온다.

---

### Edge Cases (안내문 "생각해 볼 점" — 답은 결과 보고서에)

- 회의실 예측이 다른 공간보다 어려운 이유는? 과거 센서값에 없는 정보는 무엇이고 어디서 얻나? (회의 시작 시각 → 예약 자료)
- 모델이 '지금 값'을 직접 예측할 때와 '지금 값에서의 변화량'을 예측할 때 무엇이 달라지나?
- 오차가 가장 큰 순간은 언제인가? 그 순간을 맞히는 것이 가능한가?
- (우리 데이터 사정) 학습 기간은 40~50명, 시험 기간은 17명이다. 학습 때 본 "수업 시작하면 크게 오른다"를 시험에서 그대로 하면 너무 높게 예측할 수 있다.
- (우리 데이터 사정) 입력 구간 안에 15분 넘게 빈 칸이 있으면? 기준선이 채점받은 시점에서는 모델도 반드시 예측값을 내야 같은 조건 비교가 된다.

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 과제 2의 5분 칸 표(`grid_5min.csv.gz`), 정제 규칙(`clean.py`), 기간 나누기(`split.py`), 정규화 값(`norm_stats.json`)을 그대로 쓴다.
- **FR-002**: 학습은 학습 기간(2025-09-03 ~ 2026-08-31)만, 모델 고르기(언제 학습을 멈출지, 어떤 설정이 나은지)는 검증 기간(2026-09)만 쓴다. 시험 기간(2026-10-01 ~ 10-21)은 마지막에 한 번만 채점한다.
- **FR-003**: 채점은 과제 2의 `eval_points.csv.gz` 시점 그대로, 정답이 진짜 측정값(real_*)인 칸에서만 한다.
- **FR-004**: 일정 입력은 미리 알 수 있는 것만 쓴다(수업일 여부, 수업·점심 시간, 공휴일). 예측하는 60분 동안의 일정도 미리 알 수 있으므로 넣을 수 있다.
- **FR-005**: 학습한 모델 파일과 입력 만드는 코드를 남겨 과제 6·7·8이 그대로 쓴다.
- **FR-006**: 모든 결과표에 측정 조건(데이터 기간, 실데이터, 시험 기간, 학습한 장비)을 적는다.
- **FR-007**: 학습을 여러 번 돌려도 같은 결과가 나오게 난수 씨앗(seed)을 고정한다.

### 과제 2에서 이어받는 것

| 항목 | 값 |
|---|---|
| 분석 간격 | 5분 (60분 = 12칸) |
| 공간 값 | 실습실은 기준 센서 4개 중앙값, 회의실은 센서 1개 |
| 결측 | 15분(3칸)까지 앞 값으로 채움, 더 길면 빈 칸. 채운 칸은 채점 안 함 |
| 기간 | 학습 2025-09-03~2026-08-31, 검증 2026-09, 시험 2026-10-01~10-21 |
| 일정 | 공휴일을 뺀 평일 09:00~18:00, 점심 11:30~13:00. 공휴일·휴강 목록은 `patterns.py`의 `HOLIDAYS` |
| 실습실 인원 | 이전 기수(40명대 추정, ~2025-12) → 45~50명(~2026-09-22) → 휴강(09-23~30) → 약 17명(2026-10-01~) |
| 회의실 예약 | 자료 없음 (동료 사이트에 있음, 받지 못함) |

### 넘어야 할 숫자 (시험 기간, 과제 2 기준선)

| 공간·항목 | 현재값 유지 60분 MAE | 확인 기준 |
|---|---|---|
| 실습실 CO₂ | 34.09 ppm | **23.86 ppm 이하** (30% 이상 작게) |
| 회의실 CO₂ | 63.03 ppm | **44.12 ppm 이하** |
| 실습실 온도 | 0.14 ℃ | 이보다 작게 |
| 회의실 온도 | 0.15 ℃ | 이보다 작게 |

온도는 반올림 전 값으로 비교한다(0.14와 0.14가 같아 보여도 실제로는 다를 수 있음).

그 밖에 plan에서 정한 것: 오차 함수 MAE, 검증 MAE가 10번 연속 안 좋아지면 학습 멈춤, 입력에 긴 빈 칸이 있는 표본은 학습에서 빼고 채점 시점에서는 앞 값으로 채우고 표시를 붙여 모든 채점 시점에서 예측값을 낸다.

### Key Entities

- **표본(sample)**: 기준 시각 t 하나 = 입력(t-2시간 ~ t, 24칸 × 정보 여러 개) + 정답(t+5분 ~ t+60분, 12칸 × CO₂·온도)
- **일정 칸**: 칸마다 수업일 여부, 수업 중(09~18시, 점심 제외), 점심 중, 인원(Q5)
- **모델 파일**: 학습한 가중치 + 사용한 설정(과거 길이, 입력 목록, 정규화 값)

## Success Criteria *(mandatory)*

### Measurable Outcomes (안내문 확인 기준 그대로)

- **SC-001**: 60분 뒤 CO₂ 오차가 '현재값 유지'보다 30% 이상 작다 (실습실 ≤ 23.86, 회의실 ≤ 44.12 ppm)
- **SC-002**: 온도 60분 예측이 '현재값 유지'보다 좋다
- **SC-003**: 시험 기간 데이터를 학습이나 모델 선택에 쓰지 않았다

### 산출물

- 모델 비교표(기준선 + 학습 모델, 예측 시점별 오차)
- 공간별 오차 분석과 그 원인
- 일정 정보 포함/제외 비교와 결론("일정 정보를 넣으면 60분 예측 오차가 ○ppm 줄어든다")

## Assumptions

- 개인 과제로 진행한다. 학습과 평가는 Jetson aip-1 `jiwon` 계정(`~/timeseries-inference/003-forecast/`, 가상환경 `~/eg2`)에서 한다. 과제 2 결과 파일은 Mac에서 옮겨 온다.
- 회의실은 예약 자료가 없어 회의실 일정 입력은 "수업일·시간대"뿐이다. 그래서 일정 정보의 효과는 실습실에서 크고 회의실에서는 작을 것으로 예상한다. 예약 자료를 받으면 B 심화로 다시 잰다.
- 실습실 CO₂ 30% 개선은 쉽지 않을 수 있다. 시험 기간(17명)은 변화가 작아 현재값 유지가 이미 잘 맞는다(60분 34ppm). 못 넘으면 이유를 숫자로 보인다.
- 과제 2와 마찬가지로 공간은 실습실·회의실 둘이다(안내문의 강의실 2·라운지는 데이터 없음).
