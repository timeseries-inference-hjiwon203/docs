이 문서는 과제 3을 푸는 동안 **무엇을 왜 바꿨고, 결과가 어땠는지**를 시간 순서로 적은 기록이다. 보고서(report.md)의 "실험 과정" 부분은 이 문서를 바탕으로 쓴다. 기술적인 문제와 원인 분석은 [troubleshooting.md](troubleshooting.md)에 따로 자세히 있다.

## 0. 문제와 채점 방법

- **할 일**: 실습실·회의실의 CO₂와 온도를 5분 단위로 60분 뒤까지(12칸) 예측한다.
- **데이터 나누기** (과제 2와 같음): 학습 2025-09-03 ~ 2026-08-31, 검증 2026-09(약 45명), 시험 2026-10-01 ~ 10-21(17명).
- **과제 기준** (시험 기간, 60분 뒤): CO₂는 현재값 유지보다 MAE가 30% 이상 작아야 하고, 온도는 현재값 유지보다 작기만 하면 된다.
- **비교 대상 "현재값 유지"**: 지금 값이 60분 뒤에도 그대로라고 보는 가장 단순한 예측이다. 모델이 이보다 못하면 쓸 이유가 없다.
- **공정한 평가 규칙**: 설정은 검증(9월) 점수로만 고른다. 고른 모델을 `runs/selected.json`에 적은 **뒤에** 시험(10월)을 딱 한 번 채점한다. 시험 결과를 보고 모델을 바꾸지 않는다.

검증 기간 현재값 유지(60분 뒤 MAE): 실습실 CO₂ 86.13, 회의실 CO₂ 125.40, 실습실 온도 0.164, 회의실 온도 0.270.

## 1. 처음 정한 것 (결정 가이드)

[결정-가이드.md](결정-가이드.md)에서 개념을 보고 직접 골랐다.

| 질문 | 고른 것 |
|---|---|
| 방식 | 심화(B): 딥러닝 모델 |
| 모델 | GRU부터, 나중에 LSTM·TCN 비교 |
| 과거를 얼마나 볼지 | 2시간 (나중에 1·2·4시간 비교) |
| 입력 | 센서 값, 시각·요일, 공간, 수업 일정과 인원(과거 + 앞으로 60분) |
| 출력 | 12칸을 한 번에 (직접 방식) |
| 정답 형태 | 지금 값에서 얼마나 변할지(변화량) |
| 모델 수 | 두 공간·두 항목을 모델 하나로 |
| 학습 장소 | Jetson aip-1 GPU (에폭당 약 9초) |

시작 전에 `check_data.py`로 "출력이 0인 모델 = 현재값 유지"가 과제 2 기준선 숫자와 똑같이 나오는지 확인했다. 채점 코드가 맞다는 증거다.

## 2. 실험 흐름

### 2-1. E1: 첫 모델 → 온도가 오히려 나빠짐

GRU, 과거 2시간, 변화량, 일정 포함.

| 60분 뒤 (검증) | 현재값 유지 | E1 첫 실행 |
|---|---|---|
| 실습실 CO₂ | 86.13 | 51.77 (40% 개선) |
| 회의실 CO₂ | 125.40 | 100.86 (20% 개선) |
| 실습실 온도 | 0.16 | 0.21 (**나빠짐**) |
| 회의실 온도 | 0.27 | 0.28 (**나빠짐**) |

**원인**: 온도 변화는 CO₂ 변화보다 숫자가 훨씬 작아서 학습할 때 거의 무시됐다. 또 저장할 모델을 CO₂ 점수로만 골랐다.
**바꾼 것**: 정답을 "60분 변화량의 표준편차"로 나눠 두 항목 크기를 맞췄다. 저장 기준도 **네 항목 각각 '모델 ÷ 현재값 유지' 비율의 평균**(점수, 작을수록 좋음)으로 바꿨다. → troubleshooting 1번

다시 돌린 E1: 실습실 CO₂ 47.6, 실습실 온도 0.178(아직 나쁨), 회의실 CO₂ 103, 회의실 온도 0.263. **점수 0.865**.

### 2-2. E1a·E1b·E1c: 실습실 온도 잡기

최고 에폭이 일찍 나오고 그 뒤로 나빠지는 것(외우기)이 보여서 하나씩 바꿔 봤다.

| 실험 | 바꾼 것 | 실습실 온도 | 점수 |
|---|---|---|---|
| E1 | 기본 (lr 0.001) | 0.178 | 0.865 |
| E1a | 학습률 0.0003 | 0.175 | 0.851 |
| E1b | + dropout 0.2, weight decay 0.0001 | 0.178 | 0.859 |
| E1c | + 계절(1년 중 며칠째) 입력 | **0.161** | **0.833** |

**알게 된 것**: 외우기 방지는 효과가 작았고, 계절 입력이 실습실 온도를 크게 개선했다. 9월 실습실은 에어컨 때문에 온도가 평평한데, 계절을 모르면 다른 계절의 큰 변화를 그대로 적용했던 것으로 보인다(가설). → troubleshooting 3번
**결정**: 이후 실험의 기본 설정을 E1c로 정했다.

### 2-3. E2·E3·E4: 한 가지씩만 바꿔 비교

| 실험 | 바꾼 것 | 실습실 CO₂ | 실습실 온도 | 회의실 CO₂ | 회의실 온도 | 점수 |
|---|---|---|---|---|---|---|
| E1c | 기준 (GRU 2h) | 48.8 | 0.161 | 103 | 0.252 | 0.833 |
| E2 | 일정·인원 빼기 | 53.7 | 0.159 | 102 | 0.248 | 0.839 |
| E3 | 변화량 대신 값 자체 | 54.2 | 0.207 | 105 | 0.297 | 0.965 |
| E4_gru_1h / 4h | GRU 1·4시간 | 52.4 / 49.7 | 0.158 / 0.160 | 103 / 104 | 0.258 / 0.262 | 0.843 / 0.843 |
| E4_lstm_1h / 2h / 4h | LSTM | 53.2 / 53.3 / 53.4 | 0.163 / 0.164 / 0.162 | 105 / 102 / 104 | 0.257 / 0.254 / 0.261 | 0.858 / 0.848 / 0.856 |
| E4_tcn_1h / 2h / 4h | TCN | 45.6 / **46.6** / 47.4 | 0.166 / **0.157** / 0.165 | 101 / **101** / 102 | 0.260 / **0.247** / 0.252 | 0.833 / **0.811** / 0.832 |

**알게 된 것**
- 일정 정보는 실습실 CO₂에 도움이 됐고(48.8 vs 53.7), 회의실에는 효과가 없었다. 수업 시간표는 실습실 정보이기 때문이다. 이 결과로 원래 계획한 E5를 대신했다.
- 변화량 방식이 값 자체 방식보다 확실히 낫다. 특히 온도에서 차이가 크다.
- 모델은 TCN > GRU > LSTM 순이었다. LSTM은 2~4 에폭 만에 최고점이 나와 빨리 외웠다.
- 과거 2시간이 대체로 가장 좋았다.
- TCN 2시간에서 처음으로 네 항목 모두 현재값 유지보다 나아졌다.

### 2-4. seed 반복: 차이가 운인지 확인

점수 차이(0.811 vs 0.833)가 작아서, 시작 무작위값(seed)을 바꿔 두 번씩 더 돌렸다.

| | seed 0 | seed 1 | seed 2 | 평균 |
|---|---|---|---|---|
| TCN 2h | 0.811 | 0.815 | 0.813 | **0.813** |
| GRU 2h | 0.833 | 0.846 | 0.851 | 0.843 |

**알게 된 것**: TCN의 가장 나쁜 seed가 GRU의 가장 좋은 seed보다 나았다. TCN이 더 안정적이었고(흔들림 0.004), 세 번 모두 네 항목이 현재값 유지보다 나았다.
**결정**: 최종 모델을 **E4_tcn_2h (seed 0)**로 정하고 `runs/selected.json`에 고정했다. 세 seed 평균을 내는 앙상블은 효과가 작을 것으로 보고 쓰지 않았다.

### 2-5. E6: 처음 보는 공간에도 통할까

새 강의실에 센서를 달았을 때 기존 모델을 바로 쓸 수 있는지 보려고, 한 공간으로만 학습하고 다른 공간에서 채점했다. 모두 최종 모델과 같은 TCN 2시간·E1c 설정이다. 공간 표시 입력(is_lab)은 뺐다. 한 공간으로만 학습하면 이 값이 늘 같아서, 다른 공간의 값은 17명처럼 처음 보는 값이 되기 때문이다(`--no-location`).

검증(9월) 60분 뒤 MAE (괄호는 현재값 유지 대비 개선. **굵은 칸이 학습 때 못 본 공간**)

| 실험 | 학습 공간 | 실습실 CO₂ | 실습실 온도 | 회의실 CO₂ | 회의실 온도 | 점수 |
|---|---|---|---|---|---|---|
| E4_tcn_2h (최종) | 둘 다, 공간 표시 O | 46.6 (+46%) | 0.157 (+2%) | 101 (+20%) | 0.247 (+8%) | 0.811 |
| E6_both_noloc | 둘 다, 공간 표시 X | 46.3 (+46%) | 0.175 (-10%) | 99.4 (+21%) | 0.246 (+9%) | 0.834 |
| E6_lab_only | 실습실만 | 45.5 (+47%) | 0.152 (+5%) | **114 (+9%)** | **0.329 (-22%)** | 0.902 |
| E6_meet_only | 회의실만 | **92.5 (-7%)** | **0.223 (-39%)** | 102 (+18%) | 0.248 (+8%) | 1.050 |

**알게 된 것**
1. **처음 보는 공간에서는 잘 안 통한다.** 회의실로만 배운 모델은 실습실 CO₂를 현재값 유지보다 못 맞혔다(-7%). 실습실의 수업 패턴을 회의실 데이터로는 배울 수 없기 때문이다. 실습실로만 배운 모델은 회의실 CO₂에서 조금 나았지만(+9%), 두 공간으로 배운 모델(+21%)의 절반도 안 됐다.
2. **온도는 공간마다 성질이 더 다르다.** 못 본 공간의 온도는 두 경우 모두 현재값 유지보다 크게 나빴다(-22%, -39%). 냉난방, 창문, 방 크기가 달라서 온도가 움직이는 방식이 다른 것으로 보인다(가설).
3. **같은 공간이면 두 공간을 같이 배워도 손해가 없었다.** 실습실만 배운 모델의 실습실 CO₂(45.5)와 두 공간 모델(46.3)이 비슷하고, 회의실도 비슷했다(102 vs 99.4).
4. **공간 표시 입력은 실습실 온도에 도움이 됐다.** 빼면 0.157 → 0.175로 나빠졌다.

**결론**: 새 공간에 쓰려면 그 공간의 데이터가 어느 정도 있어야 한다. 모델 하나로 여러 공간을 다루는 건 좋지만, 각 공간을 학습 데이터에 넣어야 한다.

10월 참고표(공식 결과 아님)에서도 못 본 공간은 나빴다(실습실만 → 회의실 CO₂ +2%, 온도 -47%). 반대로 실습실만 배운 모델의 실습실 CO₂는 26.6(+22%)으로, 최종 모델(38.2)보다 좋았다. 회의실 데이터가 섞이지 않은 쪽이 10월 실습실에는 나았을 수 있지만, seed 하나뿐이라 확실하지 않다.

## 4. 왜 시험에서 무너졌나 (analyze.py)

모델은 그대로 두고 오차만 시간대별로 쪼개 봤다. → troubleshooting 4번

| 실습실, 수업 중 60분 뒤 | 실제로 오른 양 | 모델이 예측한 양 | 치우침 |
|---|---|---|---|
| 9월 검증 (45명) | +169 ppm | +189 ppm | +20 |
| 10월 시험 (17명) | +58 ppm | +154 ppm | **+95** |

- 학습 기간 수업 인원은 40명과 48명뿐이었다. 10월의 17명은 처음 보는 값이라, 모델이 "수업 = CO₂ 크게 오름"을 그대로 적용해 상승을 2.6배로 예측했다(외삽 문제).
- 수업 시작 때(9시, 13시) 가장 크게 틀렸다.
- 수업 밖 시간에는 10월에도 모델이 현재값 유지보다 나았다(15.9 vs 17.0).
- 회의실은 수업 시간에 거꾸로 낮게 예측했다(치우침 -38). 예약 정보가 없어 언제 사람이 들어올지 모르기 때문이다.
- 10월의 다른 차이(환기 등)일 가능성은 배제하지 못했다.

**배운 것**: 검증 기간과 시험 기간의 조건(인원)이 다르면, 검증 점수가 좋아도 시험에서 무너질 수 있다. 미래에 학습 때 없던 조건이 올 것을 알면, 그 조건을 확인할 방법을 따로 마련해야 한다.

### 4-1. 다른 실험들의 10월 참고표 (공식 결과 아님)

최종 모델을 고정한 뒤, 나머지 모델도 10월로 채점해 봤다. **이 표로 모델을 다시 고르지 않는다.** 원인 분석에만 쓴다.

| 실험 | 9월 점수 | 10월 실습실 CO₂ | 10월 회의실 CO₂ | 10월 점수 |
|---|---|---|---|---|
| E1c (GRU 2h, 일정 O) | 0.833 | 37.6 (-10%) | 50.7 (+20%) | 0.921 |
| **E2 (GRU 2h, 일정 X)** | 0.839 | **27.9 (+18%)** | 49.9 (+21%) | **0.761** |
| E3 (값 자체) | 0.965 | 26.3 (+23%) | 54.3 (+14%) | 0.905 |
| E4_tcn_1h / 2h / 4h | 0.833 / 0.811 / 0.832 | 28.0 / 38.2 / 28.1 | 48.6 / 52.7 / 51.4 | 0.833 / 0.908 / 0.806 |
| tcn2h seed 0 / 1 / 2 | 0.811 / 0.815 / 0.813 | 38.2 / 32.2 / 29.1 | 52.7 / 51.7 / 49.9 | 0.908 / 0.836 / 0.799 |
| gru2h seed 0 / 1 / 2 | 0.833 / 0.846 / 0.851 | 37.6 / 34.3 / 35.2 | 50.7 / 49.8 / 51.4 | 0.921 / 0.880 / 0.842 |
| LSTM 1h / 2h / 4h | 0.858 / 0.848 / 0.856 | 38.9 / 36.2 / 32.1 | 52.2 / 54.0 / 55.3 | 0.933 / 0.902 / 0.880 |

(현재값 유지: 실습실 CO₂ 34.09, 회의실 CO₂ 63.03. 기준 30% 개선 = 23.86 / 44.12 이하)

**알게 된 것**
1. **어떤 모델도 10월 CO₂ 기준(30%)에 닿지 못했다.** 가장 좋은 실습실 CO₂는 E3의 +23%, 회의실은 E4_tcn_1h의 +23%였다.
2. **일정·인원을 뺀 E2가 10월에 가장 좋았다.** 일정 하나만 다른 E1c와 비교하면 실습실 CO₂가 37.6 → 27.9로 좋아졌다. 9월에는 일정이 도움이 됐는데(48.8 vs 53.7), 10월에는 오히려 해가 됐다. 4번의 "처음 보는 인원 값 때문" 가설을 강하게 뒷받침한다.
3. **처음 보는 조건에서는 seed마다 결과가 크게 갈렸다.** TCN 2h는 9월에 seed 3개가 0.811~0.815로 거의 같았는데, 10월 실습실 CO₂는 29.1~38.2로 크게 흩어졌다. 학습 때 본 적 없는 입력에 모델이 어떻게 반응할지는 정해져 있지 않아서, 시작 무작위값에 따라 달라진다.
4. **9월 순위가 10월 순위와 달랐다.** 9월 1등(E4_tcn_2h seed 0)이 10월 실습실 CO₂에서는 거의 꼴찌였다. 검증 기간이 시험 기간과 조건이 다르면 검증으로 고른 모델이 최선이 아닐 수 있다.

**만약 다시 한다면** (실제로 한 것은 아님): 인원 숫자 입력을 빼고 수업 여부만 넣거나, 인원이 다른 기간을 검증에 넣어 "인원이 바뀌어도 버티는지"를 고르는 기준에 넣는 방법이 있다.
