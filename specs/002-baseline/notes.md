### 칸 맞추기 (`analysis/resample.py`)

| 규칙 | 이유 | 근거 데이터 |
|---|---|---|
| 분석 간격 5분 | 과제 3이 5분 간격 60분 예측을 요구한다. 1분은 10분 보고 센서 칸의 90%가 비고 잡음이 남으며 모델 입력이 5배 길어진다. 10분은 과제 요구보다 거칠고 빠른 변화가 뭉개진다 | 보고 주기: 실습실 1·2·10분, 회의실 10분 |
| 센서마다 먼저 5분 평균, 그다음 공간 값 | 1분 센서가 칸 안에 기록이 많다고 공간 값에 더 크게 반영되지 않게 한다 | |
| 실습실 = 2025-09-03부터 있던 센서 4개의 중앙값 | 중앙값은 센서 하나만 튀어도 묻힌다(평균은 끌려감). 센서 구성이 1년 내내 같아야 "실습실 값"의 뜻이 바뀌지 않는다. 센서가 고장 나면 남은 센서로 계산된다 | 2026-03-25 후면 오른쪽 혼자 10,000→4,132. 새 센서 포함 7개 중앙값과 차이: 온도 평균 0.07℃, 습도 0.5% (센서 오차보다 작음) |
| 회의실 = 센서 1개 그대로 | 센서가 하나뿐이다 | |
| 채우기는 **센서마다 먼저** 하고 그다음 중앙값을 낸다 (2026-10-22 수정) | 센서마다 보고 주기(1·2·10분)가 달라 칸마다 값을 낸 센서 조합이 바뀐다. 센서끼리 100ppm쯤 차이가 나서(최솟값 411 vs 520) 조합이 바뀔 때마다 중앙값이 출렁였다. 먼저 채우면 칸마다 같은 4개 센서로 중앙값을 낸다 | 수정 전 기준선: 실습실 CO₂ 현재값 유지 오차가 5분 뒤 51.9, 15분 53.3, 30분 20.4, 60분 35.1ppm(시험). 홀수 칸(5·15분) 뒤만 크고 짝수 칸(30·60분) 뒤는 작음 → 10분 센서가 한 칸 걸러 들어오며 생긴 출렁임 |
| 빈칸은 앞 값으로 15분(3칸)까지 채우고, 더 길면 비운다 | 모델 입력에 빈칸이 있으면 계산이 안 된다. 회의실은 10분 보고라 한 칸 걸러 비고, 보고가 한 번 빠지면 15분이 빈다. 30분 넘게 같은 값을 이으면 CO₂ 변화(수업 시작 뒤 수백 ppm)를 놓친다. 앞 값 채우기는 실시간 서비스에서도 똑같이 할 수 있다(앞뒤 잇기는 미래 값이 필요해 서비스에서 못 함) | 회의실 5분 빈칸 55,080회, 15분 739회, 20~30분 27회 |
| 채운 칸은 `real_*=False`로 표시하고 채점에서 뺀다. 실습실은 4개 센서 중 하나라도 진짜 측정한 칸이면 `real_*=True` | 지어낸 값을 정답으로 채점하면 점수가 실력을 보여 주지 못한다 | |
